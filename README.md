# Python Basics Practice

This repo contains simple Python programs to understand core programming concepts, syntax, such as:
- Strings
- Loops
- Conditionals
- Functions
- basic logic building

All programs are beginner-friendly and written while learning Python using Google Colab.

## Beginner Tips to practice effectively: 

1. When writing code, use **print()** after every line
2. Understand core datatypes: int, str, list, dict, and boolean
3. Control statements: if, else, elif, for, while
4. Functions and return values
5. Learn to apply logic with teeny-tiny mini tasks (Don't overwhelm yourself with buzzwords yet!)
6. Learn by applying theory on projects, for example: BMI calculation, how to load a file, file renamer, find or count numbers.

## Intermediate Tips:

1. Learn about libraries and their application
   - **pandas:** data manipulation
   - **numpy:** numerical computing or math with arrays
   - **matplotlib:** for plots or data visualisation
   - **seaborn:** statistical visualization
     
2. Always document and track your progress.
3. Lastly: Don't RUSH. Learn at your own pace. Make mistakes.
